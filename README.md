# ICT-beleid

Statische website over het ICT-beleid van de school (apps, tools, privacy en digitale werkvormen). Puur HTML/CSS/JS — geen server, geen build-stap, geen login vereist.

## Lokaal bekijken

Open `index.html` rechtstreeks in de browser, of start een simpele lokale server, bv.:

```
npx serve .
```

## Hosten via GitHub Pages

1. Push deze repository naar GitHub.
2. Ga naar **Settings → Pages**.
3. Kies bij **Source** de branch `main` en map `/ (root)`.
4. Sla op — de site is na enkele minuten bereikbaar op `https://<gebruikersnaam>.github.io/<repo-naam>/`.

Er is geen koppeling met Smartschool of enige andere login: de site is volledig openbaar en statisch.
